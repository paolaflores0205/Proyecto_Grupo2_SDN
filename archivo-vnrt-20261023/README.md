# Código recuperado del VNRT original

Archivos seleccionados y verificados del respaldo anterior al Lab 5, fecha local 23/10/2026 (24/10 UTC). Incluye módulos Python, HTML/CSS, propiedades Floodlight y unidades systemd del controller y de h3/h4. Los datos IP/MAC/puertos y los caminos Linux son los históricos: no aplicar directamente sobre máquinas nuevas.

Se conservan versiones anteriores porque son dependencias de los módulos vigentes. Los drop-ins 80-multitabla seleccionan los puntos de entrada actuales; la precedencia de systemd importa. No ejecutar todos los scripts históricos como una secuencia de instalación.

Para un entorno nuevo usar primero el despliegue portable y su actualización multitabla. Este archivo sirve como referencia del código real y recuperación selectiva. No contiene config.json privados, cuentas, dumps MySQL, claves ni JAR.

## Datos de red anonimizados

Esta edición pública sustituye direcciones internas por las redes de documentación 192.0.2.0/24, 198.51.100.0/24 y 203.0.113.0/24; las MAC y los DPID reales también se sustituyeron. Los identificadores aquí son ejemplos y no permiten reconectar al VNRT original. Completar el inventario propio antes de generar o instalar. La copia original íntegra se conserva únicamente en el respaldo privado local. Los hashes de archivos publicados corresponden a esta edición; no se afirma identidad byte a byte con el código remoto original.
